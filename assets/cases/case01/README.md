# Case 01 - 就活コミュニティ

このフォルダには、Case 01（就活コミュニティ）の素材を配置します。

## 必要なファイル

- `CASE01_STORYBOARD.png` - ストーリーボード画像
- `CASE01_BLOCKING.png` - ブロッキング画像
- `CASE01_VIDEO.mp4` - 動画ファイル

## ファイル命名規則

- ファイル名は大文字・アンダースコア区切り
- 拡張子: `.png`, `.jpg`, `.jpeg`, `.webp`, `.mp4`

## 配置方法

1. 上記のファイル名で素材を用意
2. このフォルダに配置
3. ブラウザをリロード（Ctrl+R）

ファイルが存在しない場合は、プレースホルダーが表示されます。
