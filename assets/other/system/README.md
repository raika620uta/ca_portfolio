# このフォルダについて

このフォルダには System Development 作品の画像を配置します。

## ファイル命名規則

- `SYSTEM_01.png`
- `SYSTEM_02.jpg`
- `SYSTEM_03.webp`
- ...

**形式**: `SYSTEM_{番号2桁}.{拡張子}`

## 対応拡張子

- `.png`
- `.jpg`
- `.jpeg`
- `.webp`

## 推奨サイズ

- 横幅: 1280px以上
- アスペクト比: 16:9（1280x720、1920x1080など）

## 使い方

1. ファイルをこのフォルダに配置
2. Live Serverで自動的に反映
3. `npm run deploy`で公開
